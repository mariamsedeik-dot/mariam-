# HeartGuard — AI Clinical Risk Assessor

A Streamlit web application designed to assess clinical risk for heart conditions using machine learning techniques.

## Built With

* Python 
* Streamlit (Web Interface)
* Scikit-Learn (Machine Learning Model)
* **Pandas** & **NumPy** (Data Processing)
